# Product Images Directory

## Upload your product images here

### Naming Convention
- Use descriptive names: `product-name-1.jpg`, `product-name-2.jpg`
- Supported formats: JPG, PNG, WEBP
- Recommended size: 800x800px or larger
- Keep file sizes under 500KB for fast loading

### Placeholder Images
Until you upload real images, placeholder images will be used automatically.

### Image Requirements
- Square aspect ratio preferred (1:1)
- Good lighting
- Clean background
- High resolution
- Multiple angles per product
